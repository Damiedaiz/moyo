# MOYO JEWELS — Next.js storefront

A mobile-first jewelry shopfront with category browsing, search, a working shopping bag, and WhatsApp checkout.

## Run locally
```bash
npm install
npm run dev
```
Open http://localhost:3000

## Before launch
1. Replace the sample catalog in `app/page.tsx` with actual products, photos, and prices.
2. Set `WHATSAPP_NUMBER` in `app/page.tsx` (international digits only, e.g. `23480...`).
3. Replace social links and contact details.
4. Replace demo photography with MOYO JEWELS product photography.

## Deploy
Import this repository into Vercel and deploy as a standard Next.js app. Add `moyo.daizlab.store` in the hosting provider's domain settings.

The displayed catalog is starter/demo content; it does not claim to represent confirmed stock or final prices.
